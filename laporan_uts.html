1 Pendahuluan

1.1 Latar Belakang

Perpustakaan merupakan salah satu sumber informasi penting dalam dunia pendidikan. Pengelolaan data buku secara manual seringkali menimbulkan kendala seperti pencatatan yang tidak rapi, kesulitan dalam pencarian data, serta kurangnya efisiensi waktu. Oleh karena itu, diperlukan sebuah sistem informasi berbasis web yang dapat membantu mengelola data buku secara digital.

Pada Ujian Tengah Semester (UTS) ini, dikembangkan sebuah Sistem Manajemen Perpustakaan menggunakan framework Laravel 11. Aplikasi ini menerapkan pola arsitektur MVC (Model-View-Controller) yang memisahkan logika bisnis, tampilan, dan kontrol alur data.

1.2 Tujuan

  • Membangun aplikasi CRUD (Create, Read, Update, Delete) untuk pengelolaan data buku
  • Menerapkan arsitektur MVC menggunakan framework Laravel 11
  • Mengimplementasikan relasi One-to-Many antara kategori dan buku
  • Menerapkan autentikasi (login/logout) untuk keamanan akses
  • Mengimplementasikan fitur pencarian dan filter sebagai fitur bonus

4.2 Models

Model merepresentasikan tabel database dan mendefinisikan relasi antar tabel menggunakan Eloquent ORM.

app/Models/Category.php 
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\HasMany;

class Category extends Model
{
    use HasFactory;

    protected $fillable = ['name', 'description'];

    /**
     * Relasi: Category memiliki banyak Book (One to Many)
     */
    public function books(): HasMany
    {
        return $this->hasMany(Book::class);
    }
}

}

4.3 Controllers

Controller menangani logika bisnis, menerima request dari user, memproses data, dan mengembalikan response.

app/Http/Controllers/AuthController.php 
<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;

class AuthController extends Controller
{
    public function showLogin()
    {
        return view('auth.login');
    }

    public function login(Request $request)
    {
        $credentials = $request->validate([
            'email' => 'required|email',
            'password' => 'required',
        ]);

        if (Auth::attempt($credentials)) {
            $request->session()->regenerate();
            return redirect()->intended('/books')->with('success', 'Berhasil login!');
        }

        return back()->withErrors([
            'email' => 'Email atau password salah.',
        ])->onlyInput('email');
    }

    public function logout(Request $request)
    {
        Auth::logout();
        $request->session()->invalidate();
        $request->session()->regenerateToken();
        return redirect('/login')->with('success', 'Berhasil logout!');
    }
}
app/Http/Controllers/BookController.php 
<?php

namespace App\Http\Controllers;

use App\Models\Book;
use App\Models\Category;
use Illuminate\Http\Request;

class BookController extends Controller
{
    public function index(Request $request)
    {
        $query = Book::with('category');

        // Fitur pencarian berdasarkan judul atau penulis (BONUS)
        if ($request->filled('search')) {
            $search = $request->search;
            $query->where(function ($q) use ($search) {
                $q->where('title', 'like', '%' . $search . '%')
                  ->orWhere('author', 'like', '%' . $search . '%');
            });
        }

        // Fitur filter berdasarkan kategori (BONUS)
        if ($request->filled('category_id')) {
            $query->where('category_id', $request->category_id);
        }

        $books = $query->latest()->paginate(10);
        $categories = Category::all();
        return view('books.index', compact('books', 'categories'));
    }

    public function create()
    {
        $categories = Category::all();
        return view('books.create', compact('categories'));
    }

    public function store(Request $request)
    {
        $validated = $request->validate([
            'title' => 'required|string|max:255',
            'author' => 'required|string|max:255',
            'publisher' => 'required|string|max:255',
            'year' => 'required|integer|min:1900|max:' . date('Y'),
            'stock' => 'required|integer|min:0',
            'category_id' => 'required|exists:categories,id',
        ]);

        Book::create($validated);
        return redirect()->route('books.index')
            ->with('success', 'Buku berhasil ditambahkan!');
    }

    public function show(Book $book)
    {
        $book->load('category');
        return view('books.show', compact('book'));
    }

    public function edit(Book $book)
    {
        $categories = Category::all();
        return view('books.edit', compact('book', 'categories'));
    }

    public function update(Request $request, Book $book)
    {
        $validated = $request->validate([
            'title' => 'required|string|max:255',
            'author' => 'required|string|max:255',
            'publisher' => 'required|string|max:255',
            'year' => 'required|integer|min:1900|max:' . date('Y'),
            'stock' => 'required|integer|min:0',
            'category_id' => 'required|exists:categories,id',
        ]);

        $book->update($validated);
        return redirect()->route('books.index')
            ->with('success', 'Buku berhasil diperbarui!');
    }

    public function destroy(Book $book)
    {
        $book->delete();
        return redirect()->route('books.index')
            ->with('success', 'Buku berhasil dihapus!');
    }
}

4.5 Routes

File routes mendefinisikan URL endpoint dan menghubungkannya ke controller yang sesuai.

routes/web.php 
<?php

use Illuminate\Support\Facades\Route;
use App\Http\Controllers\AuthController;
use App\Http\Controllers\BookController;

// Redirect root ke halaman buku
Route::get('/', function () {
    return redirect('/books');
});

// Authentication Routes
Route::get('/login', [AuthController::class, 'showLogin'])->name('login');
Route::post('/login', [AuthController::class, 'login']);
Route::post('/logout', [AuthController::class, 'logout'])->name('logout');

// Book Routes (harus login)
Route::middleware('auth')->group(function () {
    Route::resource('books', BookController::class);
});

6 Kesimpulan

Pada UTS ini telah berhasil dikembangkan sebuah Sistem Manajemen Perpustakaan berbasis web menggunakan framework Laravel 11. Aplikasi ini menerapkan pola arsitektur MVC (Model-View-Controller) dan memenuhi seluruh persyaratan yang diminta:

  1. CRUD (Create, Read, Update, Delete) — Pengelolaan data buku secara lengkap dengan fitur tambah, lihat, edit, dan hapus.
  2. Relasi Database — Implementasi relasi One-to-Many antara tabel categories dan books menggunakan Foreign Key.
  3. Autentikasi — Sistem login dan logout menggunakan Laravel Auth untuk mengamankan akses ke fitur manajemen buku.
  4. Validasi Data — Validasi server-side pada semua input form untuk memastikan integritas data.
  5. Struktur Data — Tabel categories (id, name, description, timestamps) dan books (id, category_id, title, author, publisher, year, stock, timestamps) sesuai spesifikasi.

Fitur Bonus yang Diimplementasikan

  • Pencarian — Fitur pencarian buku berdasarkan judul dan penulis
  • Filter Kategori — Filter data buku berdasarkan kategori
  • Statistik Dashboard — Menampilkan ringkasan total buku, jumlah kategori, dan total stok
  • Pagination — Pembagian halaman untuk daftar buku (10 item per halaman)
  • Konfirmasi Hapus — Modal dialog konfirmasi sebelum menghapus data
  • UI Premium — Desain glassmorphism dengan animasi, dark theme, dan responsive design
